# Katalog

Prosta aplikacja desktopowa Avalonia do przeglądania i uzupełniania katalogu z pliku `dane/pozycje.txt`.

## Uruchamianie

Wymagany jest .NET SDK 10. W folderze projektu uruchom:

```powershell
dotnet run
```

Plik danych jest kopiowany do katalogu wyjściowego aplikacji. Każdy rekord ma format `tytuł;rok;ocena`.

## Zadanie 3.3 — sprawdzenie pliku reguł

Liczby złamanych reguł muszą pochodzić z porównania odpowiedzi w świeżych rozmowach. Nie przeprowadzono jeszcze tych prób, dlatego nie wpisano wymyślonych wyników:

| Próba | Złamane reguły |
|---|---:|
| Pierwsze sprawdzenie świeżą sesją | Do uzupełnienia po sprawdzeniu drugiego ekranu |
| Ostatnie sprawdzenie po poprawieniu `AGENTS.md` | Do uzupełnienia po sprawdzeniu trzeciego ekranu |

## Instrukcje edytora

Dokumentacja Visual Studio Code opisuje `AGENTS.md` jako wspólny format instrukcji dla agentów. Dla harnessu GitHub Copilot plik może znajdować się w katalogu głównym repozytorium; dokumentacja wymienia również `.github/copilot-instructions.md`. Bezpośredni adres: [Custom instructions reference](https://code.visualstudio.com/docs/agents/reference/custom-instructions-reference). Sprawdzono: 17 listopada 2026 r.

Porównanie z drugim narzędziem wymaga sprawdzenia jego dokumentacji albo wyniku drugiej osoby. Nie podano tu drugiego narzędzia ani takiego wyniku, więc porównanie pozostaje do uzupełnienia.
